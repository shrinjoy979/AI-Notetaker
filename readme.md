# AI-Notetaker

An AI-powered Note Taking application that helps capture, organize, and manage notes efficiently.

This project is designed to simulate a smart note-taking system with features like creating notes, tagging, searching, and organizing content for better productivity.

---

## Features

- Create and manage notes
- Edit and delete notes
- Tag-based organization
- Search notes by keywords
- Simple and clean API structure
- In-memory data handling
- Fast and lightweight

---

## Tech Stack

- TypeScript
- Node.js
- Express.js

---

## Project Purpose

The goal of this project is to build a simple AI-inspired note-taking backend that demonstrates how notes can be structured, stored, and retrieved efficiently. It focuses on clean API design and core functionality without external dependencies.

---

## Supported Functionality

- Create a new note
- Get note by ID
- Update note
- Delete note
- List all notes
- Search notes by keyword or tag
